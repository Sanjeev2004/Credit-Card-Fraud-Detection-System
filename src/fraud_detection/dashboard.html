Understanding the numbers

Precision

Of the transactions flagged as fraud, how many were actually fraud? Higher precision means fewer false alerts.

Recall

Of all labeled fraud cases, how many did the model catch? Higher recall means less missed fraud.

Average precision

Summarizes the precision–recall tradeoff across thresholds. The deployed model is chosen using validation AP.

Threshold and run details load from the saved report.
Results use a seeded random split of a historical dataset. They do not establish future payment performance. A model can achieve high accuracy while detecting no fraud.
